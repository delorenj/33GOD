# The Manual: visual grammar v0 ("Blip & Wall")

Status: draft v0, 2026-11-11. Initiative I-10. Owner: `33god`.
Vision: [`THE_MANUAL.md`](../../../THE_MANUAL.md). Research it stands on: [`research/`](../research/).

Rule zero: **a page may only use atoms this file defines.** A new atom needs a grammar change first, and the change cites a row in [`feedback/LOG.md`](../feedback/LOG.md).

LEGO is a trademark. Pages use generic bricks, never LEGO type or logos, and docs say "LEGO-style".

## 0. The idea in one paragraph

Every page is a LEGO-style step panel: one idea, pictures and arrows, a few 1-3 word labels. A small yellow note-character, **Blip**, *is* one event, one fact that happened. Blip is pinned on a tall blue **wall** (the bus) that keeps notes for days. Listeners read the wall at their own pace and nobody phones anybody. **Four fixed line types** say how things connect, because LEGO needs no connector atom (every brick joins the same way) and software does. A **level meter** says how deep something nests. Every page ships an evidence sheet, so a pretty page is never a wrong page.

Provenance tags used below: **[B]** Follow Blip proposal, **[S]** Slab and Stud proposal, **[T]** Technic Gauge proposal, **[L]** LEGO original atom, **[N]** new in this synthesis, **[J]** Jarad's own idea in `THE_MANUAL.md`.

## 1. Decisions that shaped v0

Architect findings were treated as vetoes, then Damian-proxy cuts, then noob-builder fixes.

| # | Decision | Why | From |
|---|---|---|---|
| D1 | The bus is a **notice wall**, not a post office, mailroom or mailbox. | Mail is addressed point to point. Pub/sub has no addressee. Architect veto on Blip's metaphor. Blip the character survives; his road becomes "pinned on the wall". | B + S, architect veto |
| D2 | **No snap imagery.** No stud-in-hole. Bricks never touch each other to announce. A note is a tile dropped in a slot. | A snapped joint teaches "A calls B" (coupling). Noob and architect both flagged it. | S fixed, noob |
| D3 | **Dapr is never bus-coloured.** It is a small sidecar bolted to the listener app, hidden until Book 1 page 7, and a squint badge marks where it hides. | Architect veto on Slab's "blue = bus, Dapr clips blue". Dapr is listen-side only and no publisher uses it. | T + B, architect veto |
| D4 | The listener's **bookmark (cursor) is drawn on the wall**, not on the brick. | A durable consumer's position lives in the NATS server. A dead listener keeps its place. | architect |
| D5 | Retention is a **tear-off calendar** on the wall, not seven drawn layers. | Layers made wall height mean "days" and fought "vertical = runs on". A calendar distorts nothing, so no squint is needed. | noob + architect |
| D6 | **Level meter = nested bars of identical squares**, depth only, 4 levels max, taken straight from the platform map's parent chain. No studs, no "kinds" rungs, no skipping. | One atom, one meaning. Both Blip's 5 rungs and its "length is depth" claim broke the 4-level cap. | J + architect + noob |
| D7 | **One hue per meaning** (section 5). Red is only for wrong or hazard. Green is only the check badge. Yellow is only things in flight. | Three proposals each reused red, green or yellow for something else. | all three judges |
| D8 | **Real name printed on the part**, small. The per-page parts box is dropped for v0. Page 0 is the full inventory. | Two names per thing (kid word plus cast box) will not survive lookup cost. | Damian + noob |
| D9 | **No terminal chips** on any page Damian reads. The 1:1 ribbon becomes a friendly "check it" (a link or an ask-your-helper prompt), or it is dropped. | He is not terminal-first. A command chip is a wall of text made of symbols. | Damian |
| D10 | **One numeral system.** Big page number only. Hop numerals are dropped (order reads left to right). Small black dots carry numerals only where an arrow loops back. | Page 1 would otherwise carry two kinds of "1". | T over B |
| D11 | **Dotted lines are never used.** A dashed outline means "not running on this reader's box". | The three proposals gave dotted three meanings. | noob |
| D12 | **Install state stays out of concept books.** Bags, open and sealed, live only in the Build book. | "Understand the model" and "what is on your Mac" are different jobs. | noob over S |
| D13 | The **squint badge** is a wink face plus a page numeral. No codes like "B1p2". | A page id is a symbol to decode. | Damian |
| D14 | **Page 1 carries at most 4 drawn things**, 1-2 line types, 2 unfamiliar names, one caption. | 5-second glance test. | Damian |

## 2. Controlled vocabulary (Book 1 cap: 60 distinct words)

Plain word first, real term bridged beside it at first use.

| Plain word | Real term | Meaning |
|---|---|---|
| **note** | event | A fact that already happened. Past tense. Pinned on the wall. Anyone may read it. |
| **job** | command | An order for exactly one worker. Leaves the wall when the worker finishes. |
| **ask** | call (HTTP, socket, hook) | One thing needs an answer and waits for it. |
| **bus** | stream on NATS JetStream | The wall. Holds notes (or jobs). Speakers and listeners both touch it. |
| **speaker** | publisher | Puts notes on the wall. |
| **listener** | subscriber (durable consumer) | Reads the wall from its own bookmark. |
| **keep** | store | Writes something down to remember (a database). |

Banned on a face: post office, mailroom, mailbox, envelope, address, deliver. Use "pin", "read", "copy". Bloodbank, NATS and Dapr are *names*, introduced one per page where the page is about them.

### 3B. Lines (the typed-connector gap)

LEGO has one stud. Software has several kinds of link. v0 has **four lines and no fifth**. Shape carries the type, colour is a redundant twin. Every arrow is exactly one of these. A "wrong" picture uses the real line type plus an X.

| Line | Looks like | Means | Touches | Accuracy note |
|---|---|---|---|---|
| **NOTE** | Fat arrow, round-dot tail, carrying a yellow Blip (or translucent twin) | Announce a fact. One-way. Anyone may read. Nobody waits. | A wall only (speak into it, read from it) | `bloodbank.evt.*` on BLOODBANK_EVENTS. Publish is async and fire-and-forget. |
| **JOB** | Fat arrow, square tail with a gear, carrying a Chore | One worker takes it, does it, and it is gone. | The commands wall only | `bloodbank.cmd.*` on BLOODBANK_COMMANDS, work queue, 1 day. |
| **ASK** | Thin coiled cord (a phone cord), arrowheads both ends, **hourglass** at the middle | One side needs an answer and waits for it. | Never a wall | hook to hook-hub, hook-hub to Candystore context, Dapr sidecar to the app. A socket call is an ask. |
| **KEEP** | Arrow ending in a purple drum | Write it down to remember. | A drum | Postgres inserts, Hindsight retain. |

The hourglass belongs on every ASK, because "someone waits" is what makes it an ask. Never draw an hourglass on a NOTE.

## 4. Page template (regions)

Portrait 3:4, one screen, nothing scrolls. Warm tan paper (never black: dark bricks vanish on black). Labels at least 14 px at 390 px page width. Each region carries an id so a comment can say "R2".

| Region | Share | Holds |
|---|---|---|
| R1 Header | about 10% | Big page numeral, 2-4 word title. Nothing else on page 1. |
| R2 Hero | at least 50% | The one idea, flat side view. The only large coloured object is the hero. |
| R3 Proof | up to 22% | One check/X frame, or one second idea inset. Never both a frame and an inset. |
| R4 Foot | about 10% | Edition stamp (machine glyph plus date digits), the level-meter chain from the page where it is taught, the optional "check it" ribbon, and the page-turn exit hook. |

The hero fills at least half the page. If a reader cannot tell what is new, move the camera. Do not add words.

## 6. Type and word budget

Counted by script over the visible text of the page source. Digits, icons, check and X marks are free. A name counts as 1 word.

| Rule | Limit |
|---|---|
| Visible words per page | **30 hard cap** (page 1 uses 12). Unsourced hypothesis: tune from tell-backs. Cut a symbol before raising it. |
| Any label | 3 words or fewer, glued to the thing it names |
| Captions | One caption per page, 7 words or fewer. The only sentence allowed. |
| Unfamiliar real names | 2 or fewer per page. Name only what the page is about. A tool the reader already uses (Codex) is familiar. |
| New chunks | 4 or fewer (Cowan). |
| Line types | 2 or fewer on pages 1-3, 3 or fewer on any page |
| Frames | 1 or fewer |
| Squint badges | 2 or fewer |
| "+" bricks | 1 or fewer |
| Fat outlines | one idea per page |
| Distinct words across Book 1 | 60 or fewer |
| Text twin (alt text) | 60 words or fewer, off page, every page, not counted |
| Evidence sheet | Unlimited. It is the maintainer's, not the reader's. |

If two tell-backs in a row are wrong, cut words and add picture. If Damian clears three pages cold, test a cap of 40.

## 7. The nesting level meter

Jarad's idea, made countable. Full tree with evidence: [`scale-meter.md`](../scale-meter.md).

- **A bar of identical squares.** One square is the unit, repeated, never enlarged (Isotype). Not proportional lengths.
- **Length = depth in the part-of tree, nothing else.** Level 1 = 4 squares, 2 = 3, 3 = 2, 4 = 1. A circled numeral repeats the level (analog plus digital, as LEGO's axle numbers do).
- **Level 0 is the table** ("everything Jarad runs"). It has no bar. Damian's Mac Studio is its own table with no federation to Jarad's.
- **Parent means "is part of or owned by".** "Uses" is a line (NOTE, JOB, ASK or KEEP), never nesting. Peers get equal bars side by side.
- **At most 4 levels.** A fifth level means a new booklet.
- Bars nest left-aligned. The page's hero bar gets the fat outline. The foot strip shows the chain from the product down to the hero.
- The caption (once, where it is taught): **"depth, not size."** Never label levels "product / family / component". The meter is built from the map's parent chain, never from taste.
- Taught on Book 1 page 4 using only things already met. Pages before that carry no meter.
- Distinct from plates: plates are flat grey slabs under things (runs-on). Meter bars are rows of squares (part-of). Never draw one like the other. Both are drawn only on pages that need them.
- Deliberate distortion: the meter flattens "kind". A gateway sits at level 2 under its own level-1 product even though it is a component. That is the point of the squint badge on page 4.

## 8. Evidence rules

- Every claim a page draws has an evidence row in its evidence sheet: claim id, file and line (or command), box (big-chungus or Mac), date, and stable or live.
- Only **stable** facts print on the face (7 days). Live counts live in dated xN stamps that lint re-runs.
- **Code wins over docs.** When they disagree the sheet says so. Staleness compass: file mtimes, not file claims.
- Pages are drawn for the reader's own box. Mac and big-chungus differ (hook-hub socket path, listener count, VM plate). Each page is an *edition* with a machine glyph and a date on it.
- Hazards expire in 30 days unless re-proved.
- Lint (to be written, run by Candybar, never a new timer): word counts, name budget, outline count, registry-linted contract tiles, evidence rows present, hazard expiry.

## 9. Forbidden

1. Mail vocabulary or addressed metaphors (post office, mailbox, envelope).
2. Snap, stud-in-hole or any direct-contact picture for announcing.
3. A fifth line type, an untyped arrow, a dotted line, or a hop numeral.
4. A second use of any colour in section 5. Red as a fill. Green for anything but the check.
5. Drawing Dapr blue, drawing it on a publisher, or showing it before page 7 without a squint badge.
6. A planned or absent thing drawn solid.
7. Paragraphs, or any sentence beyond the one caption. A label over 3 words.
8. Live counts on a face. Command chips on a Damian page.
9. Install state (bags, open or sealed) in a concept book.
10. A claim that is not in the evidence sheet. A page that works only with page 0.
11. These sentences, because the code says otherwise:
    - "forever" or "never expires" for Candystore (no purge code, no retention promise).
    - "never stalls the agent" or "nothing is lost" (bb-hook fails open, so a down hub means no note).
    - "any listener can catch up" (it depends on that listener's own start rule).
    - "px is the only Plane writer" (policy, not behaviour: n8n's Ticket Pickup Chip and PM agents also write to Plane).
    - "Dapr over NATS carries everything", or FastAPI for Candystore (it is a Python stdlib HTTP server).
    - "a job is gone when taken" (it is gone when done; a worker that dies before finishing gets it again).
12. Printing a client's name or a secret. Copying the stale "nothing executed" header of `aperture/mirror/PLAN.md`.

## 10. Known gaps in v0

- No atom for files and symlinks as links (Skillex, the role template). First likely grammar change.
- Two-way bricks (n8n lanes, Hermes gateway: listen then speak) are untested until Book 3. The rotate arrow into plan view is the planned answer.
- Colour-blind and greyscale reading, and phone-versus-desktop, are untested with real readers.
- Contract-tile icons need a registry-driven generator. Not written.
- Whether the plain word "bus" reads as a vehicle to a non-engineer is untested.
- n = 1 reader. A fast first gate, not validation. Score tell-backs three ways (complete, incomplete but safe, wrong) and treat **wrong** as the only fail.
