### 3.1 JSON mode through the gateway

A retain-shaped call (`response_format json_object`) to Haiku 4.5 returned status 200 with the JSON **wrapped in a markdown code fence** (the gateway does not enforce JSON mode on Claude routes). Hindsight 0.10.1 strips fences before parsing (`engine/llm_wrapper.py:372-405`, "some models wrap JSON in ```json"), so retain and consolidation are expected to parse. W7-2 proves it with the real retain path.

A 220-item consolidation-style call with **no `max_tokens`** returned `finish=stop`, 13,620 completion tokens, 220 items parsed, in **74 s**. The gateway's default output cap does not truncate consolidation-sized replies.

### 3.2 Forced `tool_choice` gap (the finding that decides query and refresh)

Hindsight's reflect agent forces `search_mental_models`, `search_observations` and `recall` in sequence at the start of every run (`engine/reflect/agent.py:1009-1026`), and mental-model refresh runs the same loop. Tested from the Mac with token 129 against `automaticai/damien/claude-haiku-4.5` via api-direct, one tool declared:

| Request shape | Result |
|---|---|
| named `tool_choice`, default effort | 400 `Thinking may not be enabled when tool_choice forces tool use` |
| `tool_choice: "required"` | same 400 |
| named `tool_choice` + `reasoning_effort: medium` | same 400 |
| named `tool_choice` + `thinking: {"type":"disabled"}` | same 400 (the gateway overrides it) |
| named `tool_choice` + `reasoning_effort: none` or `low` | 400 `effort must be medium, high, xhigh or max` |
| `tool_choice: "auto"` | **200**, 1 tool call returned |
| `automaticai/auto/fast`, named `tool_choice` | same 400 (routes to Haiku) |

Cause: the gateway always sends Claude routes with thinking (effort floor `medium`), and Anthropic refuses thinking with a forced tool. Capability check from big-chungus with Jarad's own `aai:hindsight` token (free pool in scope, no cost): `automaticai/free` with a forced named tool returns 200, `finish=tool_calls`, 1 tool call (served by `nvidia/nemotron-3-ultra-550b-a55b:free`). So the free family can serve reflect and refresh; no Claude route can.

Consequence: with the token as scoped, retain, consolidation and recall work; reflect and mental-model refresh fail with 400. W7-2's acceptance (disposable bank retains, consolidates, recalls) does not call reflect, so it is not blocked.
