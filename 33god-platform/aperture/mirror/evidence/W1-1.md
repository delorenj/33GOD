## 6. launchd PATH fix (the 33GOD way: documented PATH in plists + `~/.local/bin` shims)

**Documented value**, in `~/.config/33god/launchd-agent.env` on the Mac. This is the same value the existing `io.33god.skillex-hermes-resync` plist already uses in production:

```
PATH=/Users/hellosubconscious/.local/bin:/Users/hellosubconscious/.local/share/mise/shims:/opt/homebrew/bin:/opt/homebrew/sbin:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin
HOME=/Users/hellosubconscious
```

Rules recorded with it:

- Plists can't expand variables or source files, so each 33GOD plist copies the values **literally** into `EnvironmentVariables`.
- The order is `~/.local/bin` wrappers/shims > mise shims > Homebrew > system.
- Service dirs (a venv's `bin/`, `node_modules/.bin`) may be **prepended**. Never drop or reorder the base.
- No `gnubin`.
- RunAtLoad + KeepAlive only; no interval keys.
- It mirrors big-chungus `candybar-executor.service`: `PATH=<venv>/bin:%h/.local/share/mise/shims:%h/.local/bin:…:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin`.

**Shims:** `~/.local/bin/gh`.

- `~/.local/bin` is already first on the non-interactive PATH via Damian's existing `.zshenv`, and first in the documented PATH. So one symlink fixes gh for ssh, for `zsh -lc` (no system gh exists to shadow it), and for any zsh-spawned launchd job.
- `mise doctor` itself recommends the shims dir for non-interactive setups.
- No rc edit was needed.
