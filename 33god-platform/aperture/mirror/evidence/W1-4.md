## 5. Driver finding for W7-1: hindsight-studio is one child crash away from an outage

Codex recorded only `supervisor.py` as missing. Read-only inspection of the live processes and the backup source (`~/code.backup/damian-33god-deploy/scripts/`) shows a larger dependency set and a live failure path:

- **Both live processes run from the deleted tree.** PID 33538 runs `…/hindsight-lifecycle-v3/supervisor.py`. Its child PID 33554 runs `…/hindsight-lifecycle-v3/entrypoint.py`. Both started Wed Oct 28 14:56:31, and both cwds are `~/.local/share/hindsight-studio/lifecycle-v3`. `~/code/damian-33god-deploy` does not exist at all.
- **Code layout W7-1 must restore together.** `supervisor.py` sets `ROOT=Path(__file__).resolve().parent` and spawns `ROOT/'entrypoint.py'`. `entrypoint.py` does `from supervisor import config,R,ROOT`, then `sys.path.insert(0, ROOT.parent/'hindsight-auth-staged')` and `from studio_asgi import create_staged_app`. The minimum restore set is therefore:
  - `scripts/hindsight-lifecycle-v3/supervisor.py`, 10,203 B, sha256 `a992ead371b59303…`
  - `scripts/hindsight-lifecycle-v3/entrypoint.py`, 1,061 B
  - `scripts/hindsight-auth-staged/studio_asgi.py` and `studio_scope.py`

  The sibling layout must be preserved, because the auth path derives from `ROOT.parent`. All four files exist, read-only, in `~/code.backup`.
- **Runtime paths are absolute and still intact.** The interpreter is `R/venv/bin/python` and PG is `R/home/.pg0/installation/18.1.0/bin`, where `R=~/.local/share/hindsight-studio`. Data is in `lifecycle-v3/data`. `events.jsonl` last shows `pg_ready` → `api_started` (pid 33554) → `ready`.
- **Failure path (not hypothetical):**
  1. The supervisor does **not** respawn children in-process. While running it loops `if api.poll() is not None or pg.poll() is not None: raise RuntimeError('unexpected_child_exit')`, then reaps both children and returns exit code 1.
  2. The plist has `KeepAlive = {SuccessfulExit = false}` and `ThrottleInterval = 10`.
  3. So **any** API or PG child exit makes launchd relaunch `supervisor.py` from the missing path. Python fails at once, which gives a 10-second relaunch thrash and a `:8888` outage.
  4. No kickstart is needed for this to happen.

  PLAN risk 1 is therefore live now. **Recommendation:** run W7-1's restore-to-durable-path plus plist repair (no restart) as the next 33GOD action on the Mac.
- **Plan dependency note:** W7-1 lists "Blocked on W1-4", and W1-4's acceptance requires W7-1's repair. W1-4's triage is the input W7-1 needs, so W7-1 is unblocked now. W1-4's open acceptance item closes when W7-1 lands.
