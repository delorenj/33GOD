## 11. Findings, not proven, owner items

Findings:

1. **The README recipe does not run verbatim from the checkout.** Steps 3 to 5 call `env-op-resolve` (shebang `/usr/bin/env python3`) from inside `~/code/33GOD/candybar`; with the documented PATH that resolves to a mise shim, which exits 1 on the untrusted `mise.toml`. Prepending `<repo>/.venv/bin` to PATH fixes it (the wrapper already does). Suggested upstream wording for `deploy/mac/README.md`: "run steps 3 to 5 with `PATH=\"$PWD/.venv/bin:$PATH\"`". Not landed here: it is outside W5-2's task and Candybar upstream was not touched.
2. **Consequence of not trusting `mise.toml`:** bare `uv` and `python3` shims still fail inside that directory. `candybar` (venv shebang), the LaunchAgent (venv-first PATH) and the CLI shim are unaffected; `uv run` needs the absolute uv path, as used above. Trusting is Damian's call and carries the standing-hooks cost in section 4; recommended against.
3. **Testing Postgres auth from inside the container proves nothing.** The postgres image trusts `127.0.0.1` inside the container, so `psql -h 127.0.0.1` with a wrong password returned `1`. The valid proof is from the host over the published port (section 6). The same trap applies to any later "default password rejected" claim.
4. **Candybar's heartbeat is now a producer on the Mac bus.** `candybar.heartbeat.publisher` publishes one `bloodbank.evt.cron.tick.fired` per minute into `BLOODBANK_EVENTS` (7-day retention), so Candystore, and anything else subscribed to `bloodbank.evt.>`, ingests about 1,440 small events a day from now on. This is the same behaviour as on big-chungus and is inherent to the single clock; it is recorded because the plan said the bus containers get "read and test events only" and this is a standing producer, not a test event.
5. **`.store.lock` convention.** Another lane created `~/.config/33god/.store.lock` (07:32, W6-4) to serialise store writes. `env-op-resolve` has no write mode, so writers each roll their own; this one used `flock` on that file plus `O_APPEND`. A `put` subcommand on the resolver would remove the duplicated writers (not done).
6. **Port forwarding detail:** `127.0.0.1:8700` and `:5435` are held by Colima's lima ssh forwarder (PID 2072), not by Docker. If Colima restarts, both disappear and come back with it; the host executor depends on `5435` (see section 10 item 4).
7. **The Linux watchdog's repo-level approved record** (`repo:deploy/watchdog/candybar-watchdog.timer`) is carried in the Mac checkout's `repo` check as `approved`; it describes a systemd timer that does not exist on the Mac. It is a repo fact, not a Mac exception, and does not weaken the no-watchdog decision.
