## 6. Deviations from the task text (recorded)

- The task said "sync.py renders hooks_dir `$HOME`-relative" — implemented as **template mode for committed artifacts + literal install rendering**, because the mandated per-dialect audit found hermes and opencode cannot consume `$HOME` (documented in the agent-hooks README table). `$HOME`-in-committed-configs is the host-neutral form; both peers render identical bytes from the same code.
- `.project.json repo_path` is `~`-relative (not `$HOME`-relative) because the consumer that already expands it (flume-hr) expands `~`; the pjangler-side gap is documented rather than worked around.
- The `target-watch` candybar manifest keeps its absolute paths (job disabled; annotated) rather than being broken by a token the exec runner wouldn't expand.
