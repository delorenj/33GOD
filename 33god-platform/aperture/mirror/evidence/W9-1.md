## 4. Fixes beyond parameterizing

- **Cadence wrapper.** Before: `"$BIN" tick || echo "tick failed" >&2` on every step, so the script exited 0 over a dead sidecar and Candybar's `on_failure` could never fire. After: every due step runs (a failed tick does not skip the hourly roll), each failure is named on stderr (`tick failed (exit 7)`), and the exit status is the first failing step's. Tests cover quiet minute, `:05`, `06:00`, `06:09` (zero-padded, not octal), `06:10`, each step failing alone, all failing, a missing command, and the default command path.
- **`jev-rollup-run`** resolved JEV and Cloudflare credentials on every 10-minute tick (two 1Password reads plus a key file) that `jev-rollup` never reads (it has no `JEV_API_KEY`/`CF_*` use; its only env is `CANDYSTORE_URL`). It resolves none now.
- **`export VAR="$(cmd)"` masks `cmd`'s failure** under `set -e`, so a failed `op read` in the old wrappers silently produced an empty credential. A name that does not resolve is now a stderr warning naming the key or ref, never a value, and the tool degrades as it always did.
- **Latent `TypeError` in `delonet-daily-report/scripts/run.py`** when no mirror directory is configured (`str(mirror_dir() / date)` on `None`). Reproduced on the base code, fixed with `mirror_target_text()`, tested.
- **`hostenv.resolve_secret` leaked a literal secret.** A literal pasted into a `*_REF` key came back in the error as `'<literal>': not an op://…`. The existing test passed over it because it stripped the quoted form before asserting. Fixed in all three copies of the file; the test is strict now. Found by the new jev-secrets test, so any host.env mistake of that kind no longer prints the value.
- **`install.sh --peer`** links only `jev-rollup` and `jev-rollup-run` (no profile, no systemd, no crank tooling a peer may carry its own copy of).
- **`nightly.sh`** replaces the two duplicated infra scripts ("fix the split, not the patch"). Yesterday is computed in the config's timezone with `zoneinfo`, not `date -d yesterday`; `verified()` parses `reportctl verify` JSON in python, not `jq`. The infra files are three-line shims that exec it.
- **`reportctl`** refuses Python < 3.11 with the version it found (it uses `datetime.UTC`).
