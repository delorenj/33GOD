## 12. Findings / notes for later waves

1. **Host-side tools need the store password.** `candystore context latest`, `mise run project:sync` and anything else using candystore's default `DATABASE_URL` (`postgresql://candystore:candystore@127.0.0.1:5434/candystore`) will fail auth on the Mac by design. Run them as `env-op-resolve exec --env-file <file with DATABASE_URL=...>`.
