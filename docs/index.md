## Project Overview

33GOD combines four independently versioned components into one operational pipeline. Bloodbank owns the event vocabulary and broker contract; Candystore stores and queries event history; Holocene observes and controls the local fleet; PJangler provisions projects and Hermes agents. This documentation describes their relationships and deployment contracts. Component repositories retain authority over their internals.

## Authority and Scope

The in-scope parts are exactly Bloodbank, Candystore, Holocene, and PJangler. Live manifests, code, and tests outrank prose. Root documentation governs cross-component relationships and deployment contracts; component documentation governs internal implementation. A contradiction is recorded in [Drift Governance](./drift-governance.md), not silently normalized.
